Level 5: The Memory Locker (Variables)

Where data lives in the machine.

1. What is a Variable?

In backend engineering, we don't just print static words. We store information that changes. A Variable is a named locker in the computer's RAM (Short-term memory).

The Rule: Name = Value

2. The "Newborn" Explanation

Imagine you have a cardboard box. You write "TOYS" on the outside of the box with a marker. You put a ball inside. Whenever you shout "TOYS!", the computer brings you the ball.

3. Ways to Remember

  • The Name is the label on the box.
  • The Equals Sign (=) is the act of putting something in the box.
  • The Value is the actual thing inside the box.
