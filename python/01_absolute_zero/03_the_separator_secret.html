1. What is sep?

By default, when you use a comma in print(), Python puts a space between the items. But what if you are building a URL for Google Search or a date for a database? You need a specific "Separator."

We use a special keyword called sep= at the end of our arguments to change the glue.

2. Common Mistakes

The Missing Quotes: sep=- will crash. The separator itself is text, so it MUST be in quotes like sep="-".

Placement: The sep command must always come last inside the parentheses.
