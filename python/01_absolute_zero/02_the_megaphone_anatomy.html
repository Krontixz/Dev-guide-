Learning the grammar of Backend Engineering.

1. What is an Argument?

Everything inside the parentheses () is called an Argument. Think of the print command as a delivery truck, and the arguments as the packages inside.

Interactive Sandbox: Multiple Packages

You can print multiple things by using a Comma (,). This tells Python: "Do this, AND also do this."

TASK: Change the code to print your name and your dream salary: print("Name:", 200000)

⚠️ Common Mistake: Forgetting the comma! If you write print("Hello" "World"), Python might crash or smash them together. The comma is the "glue" that keeps arguments organized.

2. Ways to Remember

  • The Parentheses: The megaphone's mouth.
  • The Quotes: The actual sound.
  • The Comma: The breath between words.
