Level 4: Breaking the Line (\n)

The secret code for vertical space.

1. Escape Characters

Sometimes you want to hit "Enter" inside a string of text. In Python, we use the Backslash (\) to create "Escape Characters."

  • \n = New Line (Like hitting Enter).
  • \t = Tab (Adds a big space).

2. The "Newborn" Explanation

Imagine you are typing a text message. If you want to go to the next line, you hit the return button. \n is the "Invisible Finger" that hits the return button for the computer.

3. Common Mistakes

The Wrong Slash: Beginners often use /n (Forward slash). It won't work! It must be the Backslash \n.
